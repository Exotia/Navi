# Full Autonomy Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The rover drives an operator-entered waypoint list on its own, over the ground it has mapped, avoiding what the front ZED sees, with the operator able to take over or stop instantly.

**Architecture:** Arbitration first (`twist_mux` + `mode_supervisor` in front of a renamed `/rover_twist` chassis input), then the TF tree Nav2 needs, then traversability from `/localization/map`, then Nav2 planning offline, then following (RotationShim + RPP, non-holonomic) through a `twist_shaper` that uses the vendored IK as a feasibility oracle, then ground-station goals over JSON, then yard tuning. Every stage ships something usable alone.

**Tech Stack:** ROS 2 Humble on the Orin (Nav2 stack as installed, `twist_mux`, `grid_map_ros`, `grid_map_costmap_2d`), Python nodes in a new `navi_autonomy` package (ament_cmake with `ament_python_install_package`, as `navi_sim_bringup`), C++ `twist_shaper` linking `navi_sim_ik_stepper`, PySide6 + roslibpy ground station, Gazebo Classic sim with a depth camera, pytest / gtest / `ament_cmake_pytest`.

**Spec:** `docs/superpowers/specs/2026-08-29-autonomy-design.md` (decisions) and `docs/research/2026-08-29-autonomy-research.md` (option analysis, parameter starting values, sources).

## Global Constraints

- The operator always wins instantly; STOP is live in every mode; autonomy halts on localisation `SEARCHING`/`OFF`.
- Velocity limits until measured: `vx ≤ 0.45 m/s`, `vx_min ≥ −0.15`, `wz ≤ 0.4 rad/s`, `wz` accel `≤ 0.5 rad/s²`; `vy` pinned to 0; no reversing beyond 0.6 m.
- `/manual_twist` never gets test traffic; laptop tests use throwaway ROS domains (91/92); the rover's graph is domain 0.
- Nothing under `ground_station/` imports `rclpy`. `sim/src/navi_sim_ik/vendor/` is read-only.
- Rover code lives under `rover/` and is deployed with `./deploy_rover.sh [--test]`; Orin env `source /opt/ros/humble/setup.bash && source ~/workspaces/isaac_ros-dev/install/setup.bash && source ~/navi/install/local_setup.bash`. Stop the ZED container with `pkill -x component_conta` (never `pkill -f` with a pattern that matches your own ssh command line); only one wrapper at a time; keep the laptop's domain 0 free of stale sim launches.
- Commits: `git -c user.name="Ole Peters" -c user.email="ole.peters@star-dresden.de" commit ...`, full-sentence messages.
- User actions before SP4: `sudo apt install ros-humble-twist-mux` (Orin and laptop); before SP6: `sudo apt install ros-humble-grid-map-costmap-2d` (Orin).
- Interfaces consumed from SP1–SP3, exactly: `/localization/pose` (nav_msgs/Odometry, map→base_footprint, 30 Hz, stamp frozen while SEARCHING), `/localization/status` (String JSON `{"state","seconds_since_ok","source","distance_travelled","mount_offset_verified"}`), `/localization/map` (grid_map_msgs/GridMap, `elevation`, 0.10 m, map frame, ≤0.5 Hz + 10 s keepalive), `CAMERA_IN_BASE_FOOTPRINT = (0.345, 0, 0.548)` in `navi_localization.pose_composition`.

**Interfaces:**
```python
class SupervisorState:
    MANUAL = "manual"; SEMI_AUTO = "semi_auto"; AUTONOMOUS = "autonomous"; ESTOP = "estop"
    def __init__(self, takeover_magnitude: float = 0.05, stale_status_seconds: float = 3.0): ...
    def request_mode(self, mode: str, now: float) -> list[str]        # returns actions
    def estop(self, now: float) -> list[str]
    def clear_estop(self, now: float) -> list[str]                     # only via request_mode("manual")
    def on_manual_twist(self, vx, vy, wz, now) -> list[str]            # takeover while autonomous
    def on_localization_status(self, state: str, now: float) -> list[str]
    def on_tick(self, now: float) -> list[str]                          # staleness
    mode: str; reason: str; nav_active: bool; estop_latched: bool
    def status_json(self) -> str   # {"mode","reason","nav_active","estop"}
```
Actions are strings the node maps to side effects: `"cancel_goal"`, `"nav_activate"`, `"nav_deactivate"`, `"autonomy_lock"`, `"autonomy_unlock"`, `"estop_lock"`, `"estop_unlock"`, `"zero_twist"`.
